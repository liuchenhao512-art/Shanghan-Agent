# 伤寒论智能体 0.3.3 · Windows试用版

Windows x64桌面安装包，约143 MB，内含运行环境。下载 `Shanghan-Agent-0.3.3-win-x64.exe` 后运行安装，无需自行配置Python或Node.js。

## 主要功能

- 经典研读：398条条文、九家注释、原书阅读、教材解析和原文检索。
- 个人知识库：分类导入资料，支持重命名、归档、恢复及确认删除；单库或多库均可用于对话检索。
- 专题研究：正常模型对话与按需RAG检索，可连续追问、查看研读过程并核对有效引用，不设固定研读轮数上限。
- 成果保存：对话和草稿自动保存，正式笔记确认后入库，支持Markdown/PDF导出与个人资料备份。
- 0.3.3显示优化：知识库右侧提供管理菜单，移除重复的无效引用占位和回答开头固定说明，参考资料集中在回答底部。

## 使用与版本状态

未配置模型时可离线阅读、检索和导入。模型对话需在应用“设置与备份”中填写兼容接口地址、模型名称及自己的密钥。

本次发布沿用已核验的0.3.3安装包，没有重新编译或修改功能。既有程序验证包括51项后端测试、2项桌面基础测试、13组浏览器检查、26组打包程序检查和4组图标检查；模型部分使用确定性测试服务。

当前为未签名试用版。干净Windows系统安装、真实模型学术质量以及macOS两种架构实机验收仍待完成；本次不提供macOS安装包。
